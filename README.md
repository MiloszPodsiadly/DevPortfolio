# Miłosz Podsiadły — Developer Portfolio

Personal portfolio of a Junior Software Developer interested in backend development, event-driven systems, architecture and testing.

The site presents Fraud Detection Platform, StockRescue AI, Chess Project and Library, alongside an introduction, technologies and personal interests. A neon blue and violet landscape brings the projects together in English and Polish.

Built with **React, TypeScript, Vite and Tailwind CSS**, with static HTML generated for both languages.
