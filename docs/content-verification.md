# Content verification checklist

Use this before adding public portfolio claims or project cards. Nothing in this checklist claims that profile or project details have already been verified.

- Confirm every public profile and repository URL by opening it.
- Compare each project name, role, technologies, summary, problem, and solution with its current repository.
- Keep only the planned public projects: Fraud Detection Platform, StockRescue AI, and Chess Project. Do not publish HopOn Netherlands.
- Remove unsupported metrics, experience years, employer claims, demo links, and client or workplace details.
- Obtain owner approval for the final Polish and English copy and every public link.
- Check image/font ownership and licenses before adding assets.
- Rebuild both locales and inspect the generated HTML source with JavaScript disabled.
